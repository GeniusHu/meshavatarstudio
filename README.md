# MeshAvatarStudio — Create Mesh Gradient Avatars in Your Browser

> **Online**: [meshavatarstudio.com](https://meshavatarstudio.com) — free, no sign-up.

Generate colorful mesh gradient avatars — no sign-up, runs entirely in your browser, export as images.

## How it works

A mesh gradient is a smooth 2D interpolation between multiple color points. This project renders mesh gradients on an HTML5 Canvas, lets you adjust color points and export the result as a PNG.

This is an **open-source tutorial project** — feel free to fork it, learn from the mesh rendering code, and build your own gradient tools.

## Tech stack

- Pure vanilla JavaScript
- Canvas API for gradient rendering
- Static hosting on Cloudflare
